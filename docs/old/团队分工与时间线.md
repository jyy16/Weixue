## 0. 目标与铁律

**唯一目标**：8/16 前交出一份"评委看完能记住"的完整参赛方案——一个跑得通的飞书 AI 闭环 + 一段 3-5 分钟演示视频 + 一份按【40强赛模板】撰写的参赛方案文档。

三条铁律：

1. **砍功能，不砍闭环**：演示主线（音频 → 妙记 → 评估 → 多维表格 → 机器人评语 → 教师确认）必须完整，其他都是可选。
2. **每天有验收**：每项任务当天给出可验证的产出，不留"明天再说"。
3. **周五前冻结**：8/14 所有材料冻结，之后只修 bug 不改设计。

**提交方式（重要）**：8/16 前把参赛方案文档（飞书文档，须开启"互联网获取链接可阅读"权限）链接提交到官方表单；文档内附 demo 视频链接与体验入口。建议 D13 先提交链接占位，内容可持续更新到 D14。

**评分权重**：AI 应用创新性 30% / 业务价值 30% / AI 应用深度 20% / 方案完整度、可落地性与可推广性 20%——文档篇幅与演示重点按此权重分配。
