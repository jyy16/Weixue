## 0. 环境准备

- [ ] 后端可启动：`cd backend && python seed.py && uvicorn main:app`（`/api/health` 返回数据库 ready）
- [ ] 前端可启动：`npm run dev`，代理到后端正常
- [ ] 线上 demo 已更新到最新构建（gh-pages 引用当前 `dist` 的资源哈希）
- [ ] 演示数据可恢复：`restore_demo_state.py` 或 `seed.py` 后状态与预期一致

## 1. 管理大页（辩题 / 学生 / 录音录入）

- [ ] 辩题列表可增、删、改、排序，改动刷新后保持
- [ ] 学生单个/批量添加，班级 ↔ 辩题双向查看与移除
- [ ] 音频上传：选择学生 + 辩题 + 音频 → 转写成功 → 生成作答（来源标记 audio）
- [ ] 粘贴文本录入 → 生成作答（来源标记 manual）
- [ ] 上传失败的兜底提示（文件格式 / 大小 / 服务不可用）

## 2. 智能评估（认知梯度 + 教师确认）

- [ ] 按课程批量评估，进度接口正常，完成后出现 AI 初稿
- [ ] 低（1–2 年级）/ 中（3–5 年级）/ 高（6–7 年级）学生使用对应梯段维度
- [ ] 每个维度显示 A+/A/A-/B+/B/B- 六级评分 + 推理链 + 建议标签
- [ ] 教师可逐维度改分、选标签、写批注 → 确认 → "已保存"
- [ ] 刷新页面后教师评分/标签/批注仍保持（可恢复）
- [ ] 校准记录生成：确认后可在校准列表看到 AI 初评 → 教师终评 → 理由
- [ ] 原始文本（raw_text）与清洗文本（cleaned_text）均可回看

## 3. 评语生成

- [ ] 基于教师已确认的评分/标签/批注生成评语草稿

- [ ] 批量生成正常
- [ ] 机器人发送通道：权限未就绪时明确显示"待联调"，不伪造已送达
