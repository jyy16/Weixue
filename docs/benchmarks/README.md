# 性能基准成果归档

> 2026-08-14/15 真实链路实测（deepseek-v4-flash 评估/评语 + qwen3-asr-flash 转写）。
> 所有数字可由 `backend\benchmark.py` 一键复现，用法见 `backend/benchmarks/README.md`。

## 关键数字

| 环节 | 实测 |
|---|---|
| 转写 | 45s 音频端到端 3.1s（RTF 0.07×）；22 条样本平均逐字一致率 **99.0%**（中位 100%、最低 91.4%） |
| 批量评估 | 27/27、0 错误，714s ≈ **26.4s/条**（中位 24.0s） |
| 评语草稿 | **5.4s/条**（批量 6.1s/条），对比企业确认基线 3–5 分钟 → 33–56 倍 |
| 教师侧 | 人工批改 3 分钟 → AI 审阅 ≤1 分钟，**省约 67%** |
| 成本 | 27 评估 + 9 评语 ≈ **¥0.15/节课**（DS 账单 89 请求 / 161,653 token / ¥0.18 核对） |
| 校准记忆 | 9 条 A/B：45 维一致率 **27% → 40%**，AI 偏高 30 → 22（模拟教师口径） |
