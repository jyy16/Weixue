# 维学思辨星 · Aily 知识库

> 版本：2026-08-15（定稿口径）
> 用途：Aily 智能体的知识库内容，采用 IMPORT 模式导入本文档；多维表格保持 direct 连接，两者不混用。
> 口径声明：统一五维度 + 年级合格线（2026-08-11 企业对齐后）；妙记不参与产品叙事与依赖；量化数据为 2026-08-14/15 真实链路实测。

## 1. 产品一句话与定位

维学思辨星是面向 1–7 年级思辨课堂的 AI 辅助评估系统。核心立场是「AI 准备，教师决定」：AI 负责语音转写、文本清洗、维度评分初稿、追问建议、评语草稿等高频准备工作，但每个主观评价节点都设「教师决策门」，最终判断权始终在教师手里。

要解决的问题：思辨题没有唯一答案，同一段表达放在不同年龄孩子身上评价期待完全不同；全自动批改不适用于少儿思辨评价，教师又长期被逐字整理、逐份打分、从零写评语等机械劳动挤占时间。

## 2. 核心创新与评估口径

### 2.1 认知梯度 Rubric（认知适配）

- 依据 Kuhn（1999）认识论发展模型（Realist → Absolutist → Multiplist → Evaluativist），将 1–7 年级划分为三个认知梯段：基础层（1–2 年级）、发展层（3–5 年级）、进阶层（6–7 年级）。
- 企业对齐后的统一口径：**同一套五维度标准**——立意（观点鲜明）、选材（言之有物）、结构（条理清晰）、语言（用词准确）、视角（换位思考）；年级差异通过**合格线**表达。
- 合格线：1–3 年级 ≥ 2.5（B+，「敢说、说清楚」）；4–6 年级及以上 ≥ 3.0（A-，「观点明确、有依据、能换角度」）。课堂模式、智能评估、备课辅助、学情报告统一按学生各自年级的合格线判断达标。
- 加分项：「有自己/有新意」不量化分数，命中即综合评级升一档（如 A → A+），教师端显示「加分项↑」。
- 每个维度采用 A+/A/A-/B+/B/B- 六级行为锚点；A+ 仅授予明显超出年龄预期的表现，孩子不会因为没有展现超龄能力而被扣分。

### 2.2 双层评估流水线

- Layer 1 文本清洗：去除口语填充词（「嗯」「那个」「就是」）、修正错别字、规范标点，产出 `cleaned_text`；原始 `raw_text` 始终保留供教师回溯。
- Layer 2 维度评估：基于清洗稿按五维度输出六级评分 + 推理链 + 建议标签 + AI 置信度（certain_good / certain_weak / uncertain；不确定就明说不确定，绝不冒充已评）。
- 两层解耦：未来替换 ASR 或接入 OCR 只动 Layer 1，评估逻辑不受影响。

### 2.3 教师校准记忆

- 教师覆盖 AI 评分时，系统自动记录差异（AI 原评分 → 教师终评分 + 理由），存入 `calibration_records`。
- 下次评估时，从最近 10 条校准记录以 few-shot 注入 prompt，让 AI 初稿逐步贴近这位教师的评价尺度。这不是自动提分，而是让 AI 参考教师已表达过的判断方式。

## 3. 系统架构与技术实现

- 后端：FastAPI + SQLAlchemy + SQLite（本地库是唯一事实源）；路由按领域拆分为 `backend/api/*`（settings/courses/assessment/companion/recordings/comments/prep/tags/reports）。
- 前端：React 18 + Vite + Zustand + Tailwind CSS；工作台 6 页（管理 / 智能评估 / 评语生成 / 备课辅助 / 学情报告 / 标签库）+ 课堂模式（LiveCockpit 教师端 / StudentWindow 学生端）。
- 双模式：纯前端演示模式（`VITE_DEMO_MODE`，内置演示数据，GitHub Pages 托管，评委点开即用）；完整模式（连接后端真实调用 LLM/ASR/飞书）。
- LLM：OpenAI 兼容 SDK，DashScope / DeepSeek / OpenAI 可切换；当前评估与评语默认 deepseek-v4-flash。
- ASR：可插拔 provider——mock（离线演示）/ qwen_asr（推荐，百炼 qwen3-asr-flash，base64 直传免公网 URL）/ openai / dashscope；音频预处理统一转 16k 单声道 WAV。
- 一键启动：`python start.py` 自动 seed 演示数据、启动 uvicorn、按需拉起飞书 ws_listener 长连接。

## 4. 飞书集成现状

- **多维表格**：5 张表（班级 / 辩题 / 学生 / 评估记录 / 备课计划），本地 → 飞书单向同步，表格作为教师审阅与展示面；全量同步带对账清理，可一键重建（保留 base 与 Aily 连接）。
- **机器人评语卡片**：评语生成后推送卡片给教师，按钮「确认评分 / 去网页修改 / 发送给学生」经签名校验后真实回写系统。
- **学生端直发**：学生账号已绑定的场景，评语卡片可直发学生端；8/13 已在真实飞书环境验证通过（小雨、豆豆、萌萌均标记已送达）。
- **思辨星助教**：飞书机器人自然语言交互（「帮助」「讲课计划」「小雨的评语」「查 大伟」及知识库答疑），仅在教师/助教白名单内响应。
- **事件通道**：ws_listener 长连接为主，事件订阅与卡片回调统一分发；本地 NAT 友好，无需公网回调地址。
- **Aily 智能体**：已连接多维表格并能读取真实评估数据，支持评委/教师对数据提问；知识库采用 IMPORT 模式导入本文档。
- **妙记**：因比赛租户权限不可用（错误码 99991679，需用户身份授权）已搁置，不作为演示依赖；转写能力由自研可插拔 ASR 层承担。

## 6. 演示与使用方式

- 课堂模式主线：学生开麦 → 提交 → 实时转写 → AI 追问建议（最多三轮，教师决定是否采用）→ 快速评级 → 逐维确认。
- 课后工作流：智能评估（批量/单条）→ 教师审阅与校准 → 评语生成与卡片推送 → 备课辅助（薄弱维度/低分学生/讲评顺序）→ 学情报告（班级雷达图 + 家长报告）。
- 演示数据：9 名学生（小雨、豆豆、萌萌、小明、婷婷、浩浩、小杰、佳怡、大伟）× 3 辩题 = 27 条作答；默认课程为「动物应该养在动物园吗？」。
- 体验入口：GitHub Pages 纯前端演示链接（无需后端）；完整版本地 `python start.py` 一键启动。

## 7. 常见问题 FAQ

**Q：和全自动批改有什么区别？**
A：AI 只出初稿和建议，每个主观判断都经过教师决策门；教师改分即沉淀为校准记忆，AI 越用越贴近这位老师的尺度。系统卖的是审阅效率，不是替代教师。

**Q：AI 和老师评分一致吗？**
A：AI 输出是初稿，定位不是替代教师。实测中注入校准记忆后，45 个维度的一致率从 27% 提升到 40%，AI 评分偏高的情况从 30 次降到 22 次，说明校准机制在收敛；教师逐维确认本身就是设计意图。

**Q：一节课的成本是多少？**
A：27 条评估 + 9 条评语约 ¥0.15/节课（DeepSeek 官方账单核对），ASR 走百炼另行计费，整体在角级量级。

**Q：转写准不准？**
A：22 条样本平均逐字一致率 99.0%（去标点），覆盖队友语音与儿童音色；当前覆盖干净单说话人场景。

**Q：飞书 AI 能力用在哪里？**
A：多维表格同步（数据展示与审阅面）、机器人评语卡片（按钮回调回写系统）、学生端直发、思辨星助教（自然语言查询与答疑）、Aily 数据问答。妙记因比赛租户权限不可用已搁置，转写由自研 ASR 层承担。

**Q：怎么体验 / 怎么部署？**
A：纯前端演示模式托管在 GitHub Pages，点开即用；完整模式本地 `python start.py` 一键启动。LLM 与 ASR 均可插拔切换。

**Q：认知适配具体怎么落地？**
A：三个认知梯段共用同一套五维度标准，年级差异通过合格线表达（1–3 年级 ≥ 2.5，4–6 年级及以上 ≥ 3.0）；加分项命中提升评级。

**Q：这些数据可信吗？**
A：2026-08-14/15 真实链路实测，报告带模型、日期、commit 戳，可一键复现；估算与实测严格区分。

## 8. 口径边界与诚实备注

- 教师一致率参照为团队演示教师终评（模拟教师），非真实教师大规模验证。
- 转写准确率样本为合成语音（TTS），覆盖干净单说话人场景；真实家庭/课堂噪声未覆盖。
- 耗时为单机墙钟测量，单次测量为主；成本为 DeepSeek 账单核对 + 字符粗估双口径。
- 评语字数目标区间 150–250，当前实测普遍偏长（258–323 字），作为草稿供教师编辑定稿。
- 若被追问口径，标准回答：「演示数据上的实测，完整报告带模型、日期和复现方式，见 docs/benchmarks/。」
